Logos, round two

No grease-pencil ring this time. Each of these is a mark that stands on its own, drawn on a grid, flat colour only, so it stays crisp from the Play Store down to a notification. None uses a letter or the name, so a rename costs nothing.

Each one is shown big, in the three shapes phones cut icons to, on light and dark home screens, as the one-colour themed icon, and beside a name to see it as a logo. The colours are the app's Riso inks; where two inks cross, the overlap is its own flat colour, as a real overprint would be, which also means it builds as a plain Android vector.
