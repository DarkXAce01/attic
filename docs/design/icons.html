A face of its own

Attic's icon was a tilted photo with the red loop round it, which is almost exactly Sweepy's. These four each start from something only this app has. None uses a letter or the name, so they survive a rename. Each keeps the studio's red loop, as the rules ask, but small, so it signs the icon rather than being it.

Every one is shown in the three shapes phones cut icons to, at home-screen size on a light and a dark wallpaper, and as the one-colour version Android 13+ uses for themed icons.
